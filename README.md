#RumeliCare: Hospital Database Management System

#Proje Hakkında
İstanbul'da günlük 150 hasta kapasiteli bir sağlık kuruluşu için tasarlanmış İlişkisel Veritabanı Yönetim Sistemi (RDBMS) projesidir.

#Teknik Detaylar
* **Veritabanı:** SQL (MSSQL/MySQL)
* **Özellikler:**
  * 3NF (Normalizasyon) standartlarına uygun tablo tasarımı.
  * Veri bütünlüğü (Data Integrity) için Constraint ve Foreign Key yapıları.
  * Karmaşık sorgular (Stored Procedures & Views) ile raporlama.

#Kurulum
`.sql` dosyasını SQL Server Management Studio veya MySQL Workbench üzerinde çalıştırarak tabloları oluşturabilirsiniz.
